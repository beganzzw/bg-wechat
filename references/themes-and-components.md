# 包内基础排版与主题参数

本文件提供独立基础排版说明，不需要外部主题文件。以下参数表与最小示例为本次维护独立编写，不复制外部主题源码，也不代表 gzh-design 的同名主题实现。

## 基础方案

只提供一个基础方案 `basic`：白底、深灰正文、蓝色强调。根据用户已确认偏好调整参数；不把配色变体称为随包完整主题库。

| 参数 | 默认值 | 应用位置 |
| --- | --- | --- |
| 背景 | `#ffffff` | 正文外层 |
| 正文色 | `#30343b` | 段落与列表 |
| 强调色 | `#245ea8` | 小标题、少量重点 |
| 正文字号 | `16px` | 正文 |
| 标题字号 | `22px` | 原稿章节标题 |
| 行高 | `1.85` | 正文 |
| 段后距离 | `18px` | 段落 |
| 内边距 | `16px` | 正文容器 |

## 最小装配示例

按原稿顺序装配；原稿没有标题或引用就省略相应元素。示例中的文本是占位说明，交付时用原稿替换。

```html
<section style="background:#ffffff;color:#30343b;padding:16px;font-size:16px;line-height:1.85;">
  <h2 style="font-size:22px;color:#245ea8;margin:24px 0 18px;"><span leaf="">原稿章节标题</span></h2>
  <p style="margin:0 0 18px;"><span leaf="">保留原稿段落内容。</span></p>
  <p style="margin:0 0 18px;"><span leaf="">仅对原稿已有重点使用</span><strong style="color:#245ea8;"><span leaf="">少量强调</span></strong><span leaf="">。</span></p>
</section>
```

代码使用等宽字体、每行一个段落，并转义 HTML 特殊字符；保留缩进可使用字符实体，不改写代码。图片保留原图及图注，设置适合正文宽度的内联样式。列表、表格和来源依照原稿结构装配，复杂表格需核对每一项数据，不能为视觉效果删去字段。

## theme 配置流程

1. 列主题时仅列出包内 `basic` 及当前任务已保存的自定义参数，不枚举尚未安装的外部主题。
2. 根据请求记录颜色、字号、间距等参数；无明确选择时使用表中默认值。
3. 将参数应用到当前工作区的样例正文，生成完整预览。保持相同内容以便比较，不新增事实或宣传文案。
4. 使用 BG_ROOT 的 `scripts/validate_gzh_html.py` 检查正文，用 `scripts/wrap_preview.py` 生成预览；新增组件参考时以 BG_ROOT 的 `scripts/component_lint.py` 检查其参考目录。
5. 复用已有确认；需要选择视觉方案时依据实际预览确认。将选定参数与适用范围保存在用户指定项目位置，不直接改写全局技能或公共模板。

外部 gzh-design 主题仅在用户明确选择时启用，路径与缺失处理见 `layout-pipeline.md`。使用外部组件不意味着本包附带该主题；不得把其资源纳入本包分发。
