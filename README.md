# bg-wechat-tech-creator (微信公众号科技创排一体化引擎)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

**bg-wechat-tech-creator** 是一套专为科技科普、前沿 AI 评测、出海独立开发踩坑与极客行业观察打造的微信公众号**创排一体化全流程 Skill**。

它彻底打破了“写作风格”、“活人感去 AI 味”与“排版引擎”脱节的旧模式，一站式解决：
1. **内容充满 AI 模板味**（通过整合 `human-writing` 严格封杀翻案腔、提示冒号与黑话）；
2. **公域流量有阅读量却零涨粉**（通过连载悬念预告、资料前置关注闭环与官方原生名片卡解决“做无名慈善”）；
3. **排版格式繁琐且容易在微信编辑器中样式坍塌**（提供 6 套开箱即用的高保真主题与一键复制预览页）。

## 核心特性

### 1. 活人感写作与去 AI 味门禁（深度整合 human-writing）
* **实质四部曲**：代差在哪里、原理从哪来、谁在真正兴奋、致命客观死穴。换成别的技术名无法成立。
* **结构不对称**：打破「一、二、三」对称骨架，挑选核心要点剥皮抽筋讲透，段落长短悬殊，严禁元叙述。
* **自动化文本质检 (`check_prose.py`)**：初稿强制通过静态规则质检，做到：
  - `0 翻案句`（封杀“不是……而是……”、“看似……实则……”、“说到底”）
  - `0 提示冒号`（标题、小标题、正文提示严禁用冒号，仅保留直接原话引语）
  - `0 破折号`（严禁使用破折号连接句段）
  - `0 动词名词化与商业黑话`（拦截“赋能”、“矩阵”、“闭环”空用）

### 2. 粉丝留存与转化闭环（拒绝无名慈善）
* **连载悬念预告（Cliffhanger）**：正文结尾严禁纯反思或丢链接收工，强制挂钩正在进行的下一步实操（如 A/B 测试、踩坑复盘），给读者明确的追更理由。
* **干货资料前置关注路径（Lead Magnet）**：严禁引导读者在评论区留 1（无法沉淀为粉丝）；标准化动线：“关注公众号后，在后台发送「暗号」直接获取”。
* **尾部转化区（严禁给自己加戏）**：彻底杜绝大段自我感动式的煽情独白；采用【白板手绘微动图 + 单句功能指引 + 微信官方原生名片卡】标准黄金组合。

### 3. 微信官方原生名片深度支持 (`<mp-common-profile>`)
* 原生装配微信官方 `<mp-common-profile>` 自定义标签，绑定真实公众号唯一识别码（`__biz`）、CDN 头像与认证简介。
* 读者在手机微信端打开，可直接点击卡片右侧的官方绿色「+ 关注」按钮调起关注弹窗，转化路径最短。
* 预览模板内置 Shadow DOM 隔离渲染与 `no-referrer` 机制，解决微信防盗链裂图，复制到剪贴板时保留纯正原生标签。

### 4. 6 大预置排版风格矩阵 + 自定义主题生成器
| 风格名称 | 核心色调与质感 | 最佳契合题材 |
| :--- | :--- | :--- |
| **石墨极简风（默认推荐）** | `#52525B` 纯灰阶、大留白、极度克制 | 科技评论、架构反思、底层拆解、去 AI 味首选 |
| **摸鱼绿** | `#059669` 清爽绿、卡片丰富、步骤清晰 | 保姆级教程、开发指南、工具清单、方法论 |
| **红白色系** | `#DC2626` 经典红白黑对撞、力量感强 | 犀利观点、行业批判、大厂风波、重磅发布 |
| **橄榄手记** | `#1e1f23` 墨黑配暖橙、内刊编辑部质感 | 真实案例复盘、踩坑手记、工程实战沉淀 |
| **摸鱼票据风** | `#059669` 票据/门票隐喻、星级评分卡 | 产品对比、多模型跑分 PK、工具创意测评 |
| **留白禅意风** | `#4A5D52` 灰绿、极高呼吸感、极简线条 | 独立思考、极客心路历程、慢随笔 |
| **自定义生成器** | 按用户描述或参考海报实时生成组件库 | 品牌个性化定制、特定视觉风格 |

### 5. 多方案标题矩阵（强制项）
每次成稿随文附带 4 种维度的备选标题方案：
* **方案 A（痛点反差提问型）**：面向公域推荐流与“看一看”，直击工位痛点。
* **方案 B（底层机制揭秘型）**：面向极客社群与技术圈，直击因果原理。
* **方案 C（实战利差避坑型）**：面向独立开发者与出海圈，算清业务账本。
* **方案 D（短促有力断言型）**：面向朋友圈分享与短动态，正面下断言。

└── assets/                       # [资源资产]
    └── preview-template.html     # 带 Shadow DOM 原生名片支持的预览模板

## 六步标准流水线

```
[原始素材/选题] 
       ⬇
【步骤 1：硬核活人感创作】── 参考 references/writing-guide.md
       ⬇
【步骤 2：文本级去 AI 自动化质检】── 运行 python scripts/check_prose.py <草稿.md>（0 违规）
       ⬇
【步骤 3：留存与转化闭环】── 动图 + 资料暗号 + 官方原生名片（零加戏）
       ⬇
【步骤 4：视觉设计与封面】── 2.35:1 (900×383) 微信封面安全区
       ⬇
【步骤 5：排版装配与自动化交付】── 参考 references/layout-pipeline.md + themes-and-components.md
       ├─ 运行 python scripts/validate_gzh_html.py <输出.html> (合规 0 错误)
       └─ 运行 python scripts/wrap_preview.py <输出.html> (生成一键复制预览页)
       ⬇
【步骤 6：一键多平台发布（可选）】── 运行 python scripts/publish.py (自动替换本地配图至微信 CDN 并同步草稿箱)
```

## 安装与使用

### 作为 WorkBuddy AI / Claude Code Skill 使用

克隆本仓库到你的个人技能目录（或项目技能目录）：

```bash
# 克隆到个人技能目录
git clone https://github.com/beganzzw/bg-wechat-tech-creator.git ~/.workbuddy-ai/skills/bg-wechat-tech-creator

# 或直接通过包安装
python scripts/init_skill.py bg-wechat-tech-creator
```

安装完成后，在会话中直接通过指令唤起：
```
/bg-wechat-tech-creator 帮我把这篇关于开源世界模型的技术材料写成公众号推文并排版
```
